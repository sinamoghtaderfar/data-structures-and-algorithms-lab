# نمایش بصری Binary Search

[English](./VISUALIZATION.md)

این بخش نحوه‌ی اجرای الگوریتم **Binary Search** را به‌صورت بصری و مرحله‌به‌مرحله نمایش می‌دهد.

هدف از این visualization این است که نقش `low`، `mid` و `high` بهتر قابل مشاهده باشد و مشخص شود که Binary Search چگونه در هر مرحله فضای جستجو را کوچک‌تر می‌کند.

## Visualization چگونه کار می‌کند؟

Binary Search برای مشخص کردن محدوده‌ی جستجو از سه موقعیت اصلی استفاده می‌کند:

* `low` — ابتدای محدوده‌ی فعلی جستجو
* `mid` — موقعیت وسط محدوده
* `high` — انتهای محدوده‌ی فعلی جستجو

در هر مرحله، الگوریتم مقدار موجود در `mid` را با target مقایسه می‌کند.

بر اساس نتیجه‌ی این مقایسه، یکی از دو نیمه‌ی محدوده‌ی باقی‌مانده به‌طور کامل حذف می‌شود.

برای مثال:

```text
[5, 10, 15, 20, 25, 30, 35]
 ^           ^           ^
low         mid         high
```

فرض کنیم target برابر `30` باشد.

چون:

```text
30 > 20
```

دیگر نیازی به بررسی نیمه‌ی چپ نداریم.

بنابراین محدوده‌ی جستجوی جدید می‌شود:

```text
[25, 30, 35]
```

این فرآیند تا زمانی ادامه پیدا می‌کند که target پیدا شود یا محدوده‌ی جستجو خالی شود.

## Visualization چه چیزی را نشان می‌دهد؟

نکته‌ی اصلی فقط محل قرار گرفتن `mid` نیست.

موضوع مهم، **کوچک شدن فضای جستجو** است:

```text
n
↓
n / 2
↓
n / 4
↓
n / 8
↓
...
```

همین نصف شدن مداوم فضای جستجو باعث می‌شود پیچیدگی زمانی Binary Search برابر باشد با:

```text
O(log n)
```

## اجرای Visualization

از root پروژه می‌توان فایل اصلی را اجرا کرد:

```bash
python algorithms/searching/binary-search/visualize.py
```

برای اجرای یا تولید visualization مرحله‌به‌مرحله:

```bash
python algorithms/searching/binary-search/visualize_steps.py
```

> خروجی دقیق به آرایه و target تعریف‌شده در فایل‌های visualization بستگی دارد.

## نکته‌ی اصلی

برای درک Binary Search بهتر است به آن فقط به‌عنوان «مقایسه کردن اعداد» نگاه نکنیم.

ایده‌ی اصلی این است:

**در هر مرحله، فضای جستجو تقریباً نصف می‌شود.**

به همین دلیل Binary Search برای جستجو در مجموعه‌های مرتب و بزرگ بسیار کارآمد است.
