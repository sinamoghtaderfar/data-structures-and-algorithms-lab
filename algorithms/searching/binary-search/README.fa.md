# جستجوی دودویی — Binary Search

[English](./README.md)

جستجوی دودویی یا **Binary Search** یک الگوریتم سریع برای پیدا کردن یک مقدار مشخص در یک مجموعه‌ی **مرتب‌شده** است.

برخلاف جستجوی خطی که عناصر را یکی‌یکی بررسی می‌کند، Binary Search در هر مرحله تقریباً نیمی از محدوده‌ی جستجو را حذف می‌کند.

## نحوه‌ی کار

فرض کنیم آرایه‌ی مرتب زیر را داریم:

```text
[5, 10, 15, 20, 25, 30, 35]
```

و می‌خواهیم مقدار زیر را پیدا کنیم:

```text
25
```

Binary Search به این شکل عمل می‌کند:

1. عنصر وسط را پیدا می‌کند.
2. مقدار وسط را با مقدار موردنظر مقایسه می‌کند.
3. اگر مقدار موردنظر کوچک‌تر باشد، جستجو در نیمه‌ی چپ ادامه پیدا می‌کند.
4. اگر مقدار موردنظر بزرگ‌تر باشد، جستجو در نیمه‌ی راست ادامه پیدا می‌کند.
5. این روند تا پیدا شدن مقدار یا خالی شدن محدوده‌ی جستجو ادامه پیدا می‌کند.

مثلاً:

```text
[5, 10, 15, 20, 25, 30, 35]
            ^
           mid
```

مقدار وسط `20` است.

چون:

```text
25 > 20
```

دیگر نیازی به بررسی نیمه‌ی چپ نداریم.

محدوده‌ی بعدی می‌شود:

```text
[25, 30, 35]
```

این فرآیند تا پیدا شدن مقدار موردنظر ادامه پیدا می‌کند.

## پیچیدگی زمانی

| حالت         | پیچیدگی زمانی |
| ------------ | ------------- |
| بهترین حالت  | `O(1)`        |
| حالت میانگین | `O(log n)`    |
| بدترین حالت  | `O(log n)`    |

در پیاده‌سازی iterative، پیچیدگی حافظه برابر است با:

```text
O(1)
```

## شرط مهم

Binary Search فقط زمانی به‌درستی کار می‌کند که داده‌ها **مرتب‌شده** باشند.

استفاده از Binary Search روی داده‌های نامرتب تضمینی برای پیدا کردن نتیجه‌ی صحیح ندارد.

## چرا Binary Search سریع است؟

در هر مرحله تقریباً نیمی از فضای جستجو حذف می‌شود.

برای مثال، اگر تقریباً یک میلیون عنصر مرتب داشته باشیم، Binary Search در بدترین حالت فقط حدود 20 مقایسه نیاز دارد.

تفاوت اصلی را می‌توان این‌طور دید:

```text
Linear Search  -> O(n)
Binary Search  -> O(log n)
```

## مثال

```python
from binary_search import binary_search

numbers = [5, 10, 15, 20, 25, 30, 35]

result = binary_search(numbers, 25)

print(result)
```

خروجی:

```text
4
```

عدد `4` اندیس مقدار `25` در آرایه است.

## چیزهایی که در این بخش یاد گرفتم

در هنگام پیاده‌سازی Binary Search روی این موارد تمرکز کردم:

* نحوه‌ی تغییر محدوده‌ی جستجو با استفاده از `low`، `high` و `mid`;
* دلیل نیاز Binary Search به داده‌های مرتب‌شده;
* تفاوت بین `O(n)` و `O(log n)`;
* تست کردن حالت پیدا شدن و پیدا نشدن مقدار;
* نمایش بصری مراحل اجرای الگوریتم;
* استفاده از Binary Search در یک مسئله‌ی عملی.
