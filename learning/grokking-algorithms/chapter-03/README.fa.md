# فصل ۳ — بازگشت

[English version](README.md)

این فصل درباره‌ی بازگشت است؛ روشی که در آن یک تابع برای حل مسئله، دوباره خودش را فراخوانی می‌کند.

تا اینجا دو بخش اصلی هر تابع بازگشتی معرفی شده‌اند:

- **حالت بازگشتی:** جایی که تابع دوباره خودش را صدا می‌زند.
- **حالت پایه:** شرطی که باعث متوقف شدن فراخوانی‌های بازگشتی می‌شود.

بازگشت یکی از مفاهیم پایه برای الگوریتم‌های فصل‌های بعد است، مخصوصاً روش تقسیم و حل.

برای فهم بهتر این نوع توابع، بهتر است مسیر فراخوانی‌ها را حداقل یک بار مرحله‌به‌مرحله روی کاغذ دنبال کرد.

در این فصل از شبه‌کد هم استفاده می‌شود تا منطق مسئله بدون وابستگی به یک زبان برنامه‌نویسی خاص توضیح داده شود.

## یادداشت

با ادامه‌ی فصل، این فایل هم مرحله‌به‌مرحله کامل‌تر می‌شود.
