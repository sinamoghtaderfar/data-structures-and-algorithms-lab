# Chapter 3 — Recursion

[نسخه فارسی](README.fa.md)

This chapter introduces recursion, a technique where a function solves a problem by calling itself.

The main ideas introduced so far are:

- **Recursive case** — the part where the function calls itself.
- **Base case** — the condition that stops the recursion.
- Recursion is an important foundation for later algorithms, especially divide and conquer.
- Recursive functions are easier to understand when traced step by step.
- The chapter also uses pseudocode to describe algorithmic ideas without focusing on a specific programming language.
